# 每日新闻整理

本项目归档 ChatGPT 对话《每日新闻整理》中的中文每日新闻简报，并在 `PROMPT.md` 保存当时使用的完整检索提示词，便于后续沿用。

## 来源范围

归档以原对话中的每日简报为准，保留简报正文、原有引用和链接，以及当时关于核实情况与来源访问限制的说明。原对话使用的具体检索范围以完整提示词为准。

## 归档命名

每篇简报单独保存为 `news/YYYY/MM/YYYY-MM-DD.md`，日期取原简报标注的日期。例如，2026 年 11 月 18 日的简报路径为 `news/2026/11/2026-11-18.md`。

## 添加每日更新

1. 取得当天简报的原文和引用信息。
2. 按简报日期建立 Markdown 文件，保留原有段落、引用、链接及核实和访问说明。
3. 提交之前对照原文检查日期、正文和引用。来源缺失时，等取得原文后再补档。
